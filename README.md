# NewMRR GitHub Pages MVP

This is a zero-backend launch site for NewMRR Wealth Group.

## What it does

- States the offer: Skill -> Tool -> Rec Rev
- Captures a free Skill Map lead
- Builds a first Skill Map draft in the browser
- Saves leads in localStorage for now
- Gives a mailto handoff for the lead

## Deploy fast

1. Go to Settings -> Pages.
2. Set source to Deploy from branch.
3. Pick `main` and `/root`.
4. Save.
